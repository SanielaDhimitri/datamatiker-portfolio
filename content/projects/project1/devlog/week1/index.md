During the first week, I focused on understanding and planning the **Villa Room Booking System**.

I started with the **problem formulation** to define the main problem that the system should solve. After that, I analysed the **business requirements** to understand what the system should provide for guests and the administrator.

Based on these requirements, I created **User Stories** and **Acceptance Criteria** to describe what users should be able to do and when each functionality can be considered complete.

I also created **diagrams** to visualize the system, its structure and how the different parts should work together.

Finally, I wrote a **conclusion** to summarize the analysis and make sure I had a clear understanding of the system before starting the development phase.

## What I worked on

- **Problem formulation** – Defined the main problem and purpose of the project.
- **Business requirements** – Analysed what the booking system should support for guests and the administrator.
- **User Stories** – Described the required functionality from the user's perspective.
- **Acceptance Criteria** – Defined the conditions that determine when each User Story is complete.
- **Diagrams** – Visualized the structure and processes of the system.
- **Conclusion** – Summarized the analysis before moving on to development.
