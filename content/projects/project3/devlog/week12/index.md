## Week 12 – Backend and Frontend Integration

This week I focused on connecting the frontend with the backend of the **Maler & Håndværk** web application.

The goal was to allow the frontend to send and receive data through the REST API.

### Integration

I worked on:

- Connecting the frontend to REST endpoints
- Sending customer data to the backend
- Creating service requests
- Retrieving available services
- Displaying data from the database
- Handling JSON data

### Data Flow

The application follows this basic flow:

Customer → Frontend → REST API → Service Layer → DAO → Database

### What I Learned

- How frontend and backend communicate
- How to work with REST APIs
- How JSON data is sent and received
- How data moves through the different application layers
- How to connect a complete web application
